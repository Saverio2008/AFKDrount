# AFK Drount

[简体中文](#简体中文)

AFK Drount is a desktop AFK tool for Minecraft Java Edition, built on Mineflayer. Run multiple bots at once, view in-game chat, and track dropped items.

AFK Drount 是一款基于 Mineflayer 的 Minecraft Java 版挂机工具。你可以在桌面上同时运行多个 Bot，查看游戏聊天，并统计掉落物产量。

## Disclaimer / 声明

AFK Drount is an independent third-party tool. It is neither approved by nor affiliated with Mojang or Microsoft.

AFK Drount 是独立的第三方工具，未经 Mojang 或 Microsoft 批准，与两者无关联。
